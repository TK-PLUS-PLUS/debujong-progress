プロジェクト

設定

ログインしているメンバーの編集は、止めてから約1秒で自動保存されます。JSON は控えとしてダウンロードできます。

使い方

チャートの操作

  • バーを左右にドラッグすると期間がずれます。端をドラッグすると開始日・終了日だけ変わります。
  • 「メンバー」で分けると行が担当者、バーの色がジャンルです。「ジャンル」で分けると逆になります。
  • 状態・担当・ジャンルは、それぞれ別の絞り込みです。
  • 登録済みのメンバーとジャンルは、右の「管理」からまとめて編集・追加します。マイルストーンとプロジェクト名もそこにあります。
  • バーをクリックすると編集できます。行の名前をクリックするとメンバーかジャンルを編集できます。
  • マイルストーンはプロジェクト全体の節目です。菱形をドラッグすると日付が変わり、クリックで名前を編集できます。
  • GitHub でログインすると、編集は自動で保存されます。未ログインでは閲覧だけできます。

プロジェクト

トップの一覧からプロジェクトを開きます。新しい作品は「新しいプロジェクト」から追加します。アドレスは #/プロジェクトID です。
