デブ雀

担当名と日付は初期データです。バーをドラッグすると期間が変わり、クリックで内容を編集できます。変更はこのブラウザに下書きとして残り、JSON のダウンロードか「GitHubに保存」で共有します。

タスク

メンバー

設定

GitHub へ直接保存

Fine-grained personal access token で、このリポジトリの Contents を Read and write にしてください。トークンはリポジトリには書き込みません。

使い方

チャートの操作

  • バーを左右にドラッグすると期間がずれます。端をドラッグすると開始日・終了日だけ変わります。
  • バーをクリックすると編集できます。メンバー名をクリックすると担当名と色を変えられます。
  • 編集内容はまずこのブラウザの下書きに残ります。共有するには schedule.json をコミットして push するか、「GitHubに保存」を使います。

公開ページ

進捗は https://tk-plus-plus.github.io/debujong-progress/ で公開しています。編集して push すると、しばらくしてこのページにも反映されます。

手元で開く

リポジトリのフォルダで py -3 -m http.server 8765 を実行し、http://127.0.0.1:8765/ を開きます。
